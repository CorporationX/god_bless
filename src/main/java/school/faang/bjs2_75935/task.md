# Оставляем комментарий #
## Описание ##
Facebook разрабатывает новую систему комментариев, которая позволяет пользователям одновременно оставлять комментарии под постами. Ваша задача — разработать механизм добавления комментариев, когда несколько пользователей пытаются одновременно оставить комментарий под одним постом.

## Цель: ##
Создайте многопоточную систему, которая позволяет пользователям оставлять посты и комментарии одновременно, при этом гарантируя потокобезопасность операций с данными с помощью блокировок.

## Требования: ##
1. Создайте класс **Comment**, который представляет комментарий с полями:<br/>
text — текст комментария,<br/>
author — автор комментария,<br/>
timestamp — дата и время создания комментария (тип LocalDateTime).<br/>
Создайте конструктор и методы getters для этих полей.
2. Создайте класс **Post**, который представляет пост с полями:<br/>
id — уникальный идентификатор поста,<br/>
title — заголовок поста,<br/>
content — текст поста,<br/>
author — автор поста,<br/>
comments — список комментариев (List<Comment>).
3. Создайте класс **PostService**, который будет управлять постами.<br/>
Он должен:<br/>
Хранить список постов в переменной **posts**. Подумайте, каким ключевым словом можно обозначить переменную **posts**, чтобы обеспечить согласованный доступ к этим данным из нескольких потоков<br/>
Содержать метод **addPost(Post post)**, который добавляет пост в список. Используйте блокировку **(lock)** для обеспечения безопасности данных.<br/>
Содержать метод **addComment(int postId, Comment comment)**, который добавляет комментарий к посту по его идентификатору. Для обеспечения безопасности данных при добавлении комментариев также используйте блокировку **(lock)**.<br/>
Реализовать методы для просмотра и удаления постов и комментариев.
4. Создайте класс **Main**, в котором:<br/>
Симулируется работа нескольких пользователей, добавляющих посты и комментарии одновременно.<br/>
Для каждого запроса на добавление поста или комментария создайте новый поток.<br/>
Каждый поток должен вызывать методы **addPost()** и **addComment()** для выполнения операций.<br/>
5. Обеспечьте возможность удаления постов и комментариев только тем пользователям, которые их создали. Реализуйте методы для удаления постов и комментариев с проверкой на авторство.

## Подсказки ##
Как обеспечить потокобезопасность при работе с постами и комментариями?
Для потокобезопасной работы с постами и комментариями, когда несколько потоков одновременно обращаются к этим данным, нужно использовать блокировки. Для этого можно применить ReentrantLock из пакета java.util.concurrent.locks. Пример:
```
public class PostService {
private final List<Post> posts = new ArrayList<>();
private final Lock lock = new ReentrantLock(); // Блокировка для обеспечения безопасности

    // Метод для добавления поста
    public void addPost(Post post) {
        lock.lock();
        try {
            posts.add(post); // Потокобезопасное добавление поста
        } finally {
            lock.unlock();
        }
    }

    // Остальные методы
}
```
Как разрешить удаление постов и комментариев только их создателям?
Чтобы разрешить удаление постов и комментариев только их создателям, нужно проверять автора при вызове методов удаления. В классе PostService мы проверяем, совпадает ли автор текущего поста или комментария с автором, который запрашивает удаление. Пример:
```
public void deletePost(int postId, String author) {
    lock.lock();
    try {
        posts.removeIf(post -> post.getId() == postId && post.getAuthor().equals(author)); // Удаление только автором поста
    } finally {
        lock.unlock();
    }
}

public void deleteComment(int postId, LocalDateTime timestamp, String author) {
    lock.lock();
    try {
        for (Post post : posts) {
            if (post.getId() == postId) {
                post.getComments().removeIf(comment ->
                    comment.getTimestamp().equals(timestamp) && comment.getAuthor().equals(author));
            }
        }
    } finally {
        lock.unlock();
    }
}
```
